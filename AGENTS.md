# CRE Expected Loss project instructions

Apply `docs/prompts/CRE_PROJECT_META_PROMPT.md` to all substantive work in this
repository. Before lifecycle work, use the matching template under
`docs/prompts/tasks/`.

The meta-prompt controls when a task template is silent. Direct user
instructions control when they explicitly override either document.

Do not claim regulatory compliance, model approval, validation completion, or
production readiness without required evidence and authorized institutional
decisions. Treat `data/raw/` as immutable when that directory is introduced.
Never commit credentials, confidential borrower data, or generated datasets.
