# Public-data source selection

This directory records proposed public sources for the CRE expected-loss
development stage. Selection means suitable for controlled feasibility work;
it does not establish licensing approval, representativeness, model fitness, or
production authorization.

- `public_source_selection.md` — source hierarchy, rationale, limitations, and
  acquisition sequence.
- `field_mapping.md` — provisional mapping from source families to the model
  data dictionary.
- `../../config/public_sources.yaml` — machine-readable acquisition registry.

No source data are committed to Git. Each retrieval must create a manifest with
the source URL, retrieval time, availability/publication date, terms reference,
checksum, schema version, and row-count reconciliation.
