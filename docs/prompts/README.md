# CRE project prompt system

`CRE_PROJECT_META_PROMPT.md` is the stable project constitution. Copy the
relevant template from `tasks/` into a work request and complete fields that
materially affect the task. Leave unknown institutional facts as `TBD`.

```text
Direct task instruction
        ↓
Lifecycle task template
        ↓
CRE project meta-prompt
        ↓
Repository conventions and approved artifacts
```

Available templates cover model development, model validation, ongoing
performance assessment, and lifecycle documentation.
