# Paper writing instructions

Apply repository AGENTS.md and CRE_PROJECT_META_PROMPT.md. This is a manuscript
workspace, separate from model development. Use manuscript.md as current working
source until a deliberate transition to LaTeX. Do not invent authors, affiliations,
results, references, approvals or novelty claims. Preserve population, target,
metric units, date assumptions and development-versus-independent-validation
qualifications. Link central claims to evidence/claim_register.md. Do not publish
loan identifiers, raw data or restricted artifacts. Cite original sources; mark
unverified bibliographic details and draft decisions clearly. Keep initial drafts
unsubmitted; external submission requires author review and explicit authorization.
